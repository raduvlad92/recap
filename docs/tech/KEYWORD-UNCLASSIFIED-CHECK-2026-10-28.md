## Confirmed problems and reference disagreements

**Arabic name loss is a host defect.** Both DeepSeek extractions returned the Arabic GT2 name `جي تي 2`; Sol accepted it. The source joins the conjunction to its beginning: `وجي تي 2`. The current Unicode word-boundary test finds zero bare-name occurrences and one whole prefixed occurrence, so finalization discards the approved name. The full saved-response trace reproduces the loss with no new model call. This is not an extraction omission or a corrected source spelling.

**An explicit dashboard label is missed.** The Arabic transcript quotes the dashboard warm-up-mode label `وضع التسخين`. Neither extraction nor the checker's missing-name sweep supplies it. It is a clear source-grounded example of a named setting expressed with ordinary words.

**Base-name coverage is inconsistent.** The gaming result keeps the complete game/technology names but omits five separate base/franchise entries expected by the current parent/family/version policy. Two were explicitly rejected by the checker; three were not separately added. This is narrower than saying the complete game names disappeared.

**Ambiguous ad text is accepted too confidently.** One transcript token is accepted as a brand although the text does not settle whether it is a name or a garbled capacity expression. Keeping its uncertainty private would be safer. No external correction or guessed brand is warranted.

The reference audit also prevents several misleading failure claims:

- The car result contains a valid source-literal model alias missing from the reference. Its accepted spelling is not an invented name.
- An unresolved outside-world device identity does not, by itself, make the literal device-name role uncertain. A quoted social-video caption is not necessarily a work title. Private review of the lowercase continuity phrase is defensible.
- The frozen checker explicitly excludes currency units, while the first reference requires a full currency name. Geographic qualifiers remain included by the checker; that distinction needs consistent reference treatment.
- The production behind-the-scenes transcript has an unresolved person's name boundary. The reference should not require one shorter spelling as if audio had proved it.
- A state name remains inside the accepted city/state label; missing a separate state entry is not total place-name loss or a host anchoring defect.
- Generic/noisy module labels need consistent treatment under the generic-class versus named-standard rule.
- A geographic adjective and a literal honorific alias in the gaming result are source-supported but absent from the reference. Private review of an awards phrase is defensible.
