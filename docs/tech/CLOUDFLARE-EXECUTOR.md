## Implementation

`cloudflare-prepared-artifact.mjs` binds a complete active manifest to the exact successful manual preparation run, skipped deployment and unexpired native archive checksum. Historical inspection cannot authorize executor actions. `cloudflare-handover-git.mjs` stores a closed-schema full-artifact plan/checkpoint, monotonically numbered writes and expected-blob SHA acknowledgement on the fixed branch/path. Changed or concurrent checkpoints require explicit restoration.

`cloudflare-handover-executor.mjs` composes the runtime, delivery, old-key fence and acknowledged journal operations. It rehashes local files, rechecks source identity/bounds and admitted Worker versions, verifies five independent evidence identities and a separate recovery proof, and saves native intents and deployment-selection witnesses before mutation. It supports own-revision lost-reply reconciliation and preserves legitimate business work after an acknowledged resume. Operator-intervention errors require a new plan. This is a trusted local library with no public route or apply CLI; private credentials stay local.

Recovery now durably acknowledges the restored database revision in a distinct `restore-committed` phase **before** source/Worker restoration. It then disables the pinned source and restores only the proved jobs/web versions and exact assets/configuration, leaving Cloudflare ownership, Netlify fencing and pause intact. It retains the delivery consumer for draining and never purges queued work, clears holds or marks uncertain jobs settled. Delivery intents now use the same canonical digest as the durable checkpoint validator; real-delivery composition tests cover that boundary.
