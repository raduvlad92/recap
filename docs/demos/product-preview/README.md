# therecap visual concept v0.1

Created 19 October 2026 with the frontend-design skill, under the founder's explicit request for a nonfunctional visitor demo. This authorizes the concept only; SPEC/PLAN v1.0 remain unapproved.

Open [index.html](index.html) directly in a browser. The font, icons, styling, fictional content and small local script are embedded; no installation, build, account or internet connection is required to view it.

For the shared browser, a local static server was started at http://localhost:4187. That temporary process may stop between sessions. To restart from the repository root:

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory docs/demos/product-preview
```

## What to explore

- The product-led visitor page and daily reading surface.
- Monday's seven updates from seven fictional source families, grouped into three topics.
- Source expansion, snippets, a disclosed sponsor, brand mentions, original-update previews and separate creator-linked references.
- All updates and the full nine-source coverage list, including one quiet and one delayed source.
- Sunday, with its own four updates and visible correction; Saturday, a genuinely quiet day.
- Preferences: chosen interests, delivery time and small recap-language examples for a future briefing. Past recaps stay unchanged; nothing is saved or scheduled.
- An explanatory starter-collection/pasted-link preview.
