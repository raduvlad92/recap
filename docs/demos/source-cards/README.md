# Shared source-card demo

Run `npm run dev`, then open `http://127.0.0.1:5173/docs/demos/source-cards/`.

This uses the real card components with clearly labeled synthetic content. It does not authenticate, contact creator sources, collect content or write a reader workspace. It is a local verification page, separate from the hosted owner feed.

Switch Compact/Regular, resize to 1496/1051/560/390/320px, open Full transcript, activate a keyword, navigate the image carousel and open View larger. Check the confirmed reply, missing original, quoted post, text-only post and long publication name. Both densities must retain the left source panel and right content column without horizontal overflow.

Evidence and release status: [design record](../../design/SOURCE-CARDS.md). The static covers and all post/video wording on this page are synthetic design fixtures.
