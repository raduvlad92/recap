# recap/ v0 design plan

The founder's supplied reference is the visual authority: a quiet, creator-led reading workspace with an off-white canvas, generous central reading column, creator navigation on the left and a compact signal map on the right. The daily topic recap stays one useful view beside the source updates.

## Tokens and layout

- Canvas `#f8f8f6`, paper `#ffffff`, ink `#20231f`, muted `#858b82`, line `#dedfd9`, teal `#519c8d`.
- Onest variable sans throughout. Tight, large 56px desktop headline; readable 16px body; 12–14px utility text. No external font requests.
- Desktop: 250px following/library rail, flexible central feed, 280px signal/context rail. Compact sticky header holds view tabs, search and account controls. Cards pair locally hosted abstract cover artwork with clear creator, source, summary and topic metadata.
- Tablet: right rail moves below the reading column. Phone: header and source drawer collapse gracefully; reading cards become vertical; all actions remain reachable by touch and keyboard.

## Reference review and deliberate differences

Keep the reference's rounded segmented control, creator avatars, large airy heading, rounded media cards and restrained green emphasis. Use actual filtered counts instead of inconsistent decorative figures. Replace the reference's `signal/` brand with `recap/`. An explicit Today view demonstrates cross-source synthesis; source-led All updates, Videos and Articles preserve the founder's browsing model. A studio expands to its presenters and source channels rather than flattening every account into a person.

No marketing hero, testimonial strip, gradient page wash, vanity engagement graph or fake notification button. The signal chart reflects the selected available updates. Fictional seed content is labeled in the workspace and on each sample card; saved items and preferences are real personal state. Source controls state pending/running/failed collection honestly.

## Local interactions and verification

Every visible button changes an actual view/state, opens meaningful details or follows a real original link. Search, topic/platform filters, dates, saves/read-later, individual/studio/channel navigation, sources, settings and export/reset are included. Interface language is separate from future recap language. No generated translation or scheduled email is claimed. Check type safety, desktop/phone layouts, keyboard focus/dialog behavior and empty/error states before handoff.
