# Keep historical order separate from topic relevance

The founder chose date-ordered history, explicit interest controls for prioritizing topics within each day, and an all-updates option in Q9 (D11). This preserves a dependable historical line and reader control while allowing useful personalization; it trades implicit behavior-based ranking for a product promise future changes must respect. The topic recap remains primary, and the all-updates option does not reproduce full originals.
